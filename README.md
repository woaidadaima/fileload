# fileload
大文件上传练习
# 前端
1. Vue3 + vite
2. Element-ui
3. Blob#slice 实现文件切片
4. FileReader + WebWorker + spark-md5 生成文件 hash
5. xhr 发送 formData
# 前端启动
1. 安装依赖:pnpm install
2. 启动项目:pnpm run dev
3. 打包:pnpm run build

# 后端
1. node@20.15.0
2. multiparty 处理 formData
# 后端文件启动脚本
1. cd 进入server目录
2. 安装了nodemon，使用 nodemon ./index.js，否则 node ./index.js
